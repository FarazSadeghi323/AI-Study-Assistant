# 🤖 AI Study Assistant

An AI-powered desktop application built with **Python** and **CustomTkinter** that helps students study more efficiently by interacting with PDF documents.

The application can summarize lecture notes, generate quizzes and flashcards, and answer questions based on uploaded PDF files using Large Language Models (LLMs).

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/FarazSadeghi323/AI-Study-Assistant.git
```

Go to the project directory:

```bash
cd AI-Study-Assistant
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment:

Windows

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python src/gui.py
```
